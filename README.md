# multilingual-comment-system
Advanced multilingual commenting system with instant Translate. Displays username, avatar, location, time &amp; edited status. Supports like/dislike, reply, @mention, edit/delete in 5 mins, sort by newest/oldest/liked/relevant. Blocks abuse, spam, duplicate, emoji spam, malicious links &amp; flooding via filters, rate-limit &amp; CAPTCH. Keeps history &amp; logs.
